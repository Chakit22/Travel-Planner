Diagram 02 / In Action

How Claude thinks in turns, and how the companion wakes up

On the left — what happens between Claude and a tool, in plain English. On the right — how Atlas turns into your live travel buddy the moment you land somewhere.

Tool-use loop

Claude requests, the system acts, the file updates

Like a chef calling out an order to the kitchen, getting the dish back, then deciding the next move.

01
Claude says

"I need flights."

Claude doesn't search itself — it raises its hand and asks.

02
System runs the tool

Searches, returns prices

The flight tool calls a real source and brings back live data.

03
Claude reads it

"Now I need hotels."

Same loop. Pick the next tool. Send the next request.

04
System runs it

Hotels, places, opening hours

Each result feeds back. Each round adds context.

05
Claude updates the file

"Save destination = Vietnam"

Claude calls the "save" tool. The traveller's record is written to the database.

06
Final answer

Day-by-day plan, streamed live

When Claude has enough, it writes the trip word by word.

Why this matters → Claude never makes things up. Every fact in your trip came from a real tool call, and every preference you mentioned was filed before the answer landed.
